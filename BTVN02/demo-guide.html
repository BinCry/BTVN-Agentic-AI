BTVN #1 · Google AI Studio

Chạy Issue Triage với Gemini

Năm demo: gọi LLM, đo token offline, structured output + Pydantic, function calling có trace và giao diện Streamlit.

Chuẩn bị một lần

Không hardcode API key. Các demo đọc .env trong thư mục này. Chỉ cần key từ Google AI Studio; không cần cấu hình endpoint riêng. 
Set-Location 'D:\BTVN-Agentic-AI\BTVN02'

# Tạo môi trường và cache pip ngay trong thư mục bài tập (ổ D:)
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -X utf8 -m pip install --cache-dir .\.pip-cache -r requirements.txt

# Chỉ tạo file chứa key nếu .env chưa tồn tại, tránh ghi đè cấu hình đã nhập
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
notepad .env

Nội dung cần có trong .env:

GEMINI_API_KEY=dán_key_từ_Google_AI_Studio_vào_đây
GEMINI_MODEL=gemini-3.5-flash-lite

Nếu AI Studio của bạn hiển thị model khác, thay đúng tên model đó. Khi nộp link source công khai, chỉ upload các file source; tuyệt đối không upload .env, .venv hay cache. File .gitignore đã chặn chúng nếu bạn dùng Git.

Chạy lần lượt Demo 00–04

00

LLM call tối thiểu

Kiểm tra key, model và Gemini API bằng một câu trả lời tự do.

.\.venv\Scripts\python.exe -X utf8 .\00_minimal_triage.py
.\.venv\Scripts\python.exe -X utf8 .\00_minimal_triage.py --issue "Đăng nhập trả HTTP 503 cho toàn bộ người dùng từ 09:15."
01

Đo token tiếng Anh và tiếng Việt — không gọi Gemini

Chỉ dùng tiktoken, không dùng Gemini hay API key. Lần đầu thư viện có thể tải dữ liệu tokenizer vào .tiktoken-cache trong workspace; các lần sau dùng cache. Đây là so sánh minh hoạ, không phải số token tính phí của Gemini.

.\.venv\Scripts\python.exe -X utf8 .\01_measure_tokens.py
02

Structured output + Pydantic validation

In prompt-only response, sau đó yêu cầu Gemini trả JSON schema và validate lại thành IssueTriage ở phía application.

.\.venv\Scripts\python.exe -X utf8 .\02_structured_output.py
03

Function calling có application control

Output phải có: model đề xuất get_component_owner → application validate/thực thi → tool result → final response. Application chỉ cho phép payment, identity, search.

.\.venv\Scripts\python.exe -X utf8 .\03_function_calling.py
04

Streamlit UI

Mở URL Local mà terminal in ra, nhập issue rồi bấm Phân loại issue. UI hiện component, team phụ trách và trace.

.\.venv\Scripts\python.exe -X utf8 -m streamlit run .\04_streamlit_triage.py --server.headless true

Mở qua LAN (tuỳ chọn)

Chỉ trong mạng đáng tin cậy. API key vẫn ở server, nhưng người khác mở được URL có thể dùng quota Gemini của bạn.
.\.venv\Scripts\python.exe -X utf8 -m streamlit run .\04_streamlit_triage.py --server.address 0.0.0.0 --server.port 8501 --server.headless true

Xử lý lỗi nhanh

GEMINI_API_KEY is required

Kiểm tra bạn đã tạo .env cùng cấp với các file demo, ghi đúng tên biến và đã lưu file.

404 hoặc model not found

Đổi GEMINI_MODEL thành tên model mà Google AI Studio hiển thị cho key của bạn.

429 / quota

Chờ quota làm mới hoặc chọn model/quota phù hợp trong Google AI Studio. Demo 01 vẫn chạy offline.

503 UNAVAILABLE / high demand

Google đang quá tải model. Thử GEMINI_MODEL=gemini-3.5-flash-lite, chờ vài phút rồi chạy lại; đây không phải lỗi Python.

PowerShell chặn Activate.ps1

Không cần activate: các lệnh trong hướng dẫn đã gọi trực tiếp .\.venv\Scripts\python.exe.
